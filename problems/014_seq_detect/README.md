# 014 序列检测 Sequence Detector

**难度**：Medium ｜ **类型**：状态机 ｜ **来源**：字节跳动一面（状态机实现，面试官追问重叠检测）；平头哥一面；兆芯「串行序列检测 11010」；华为 2024；几乎必考

## 题目
`din` 是串行输入，每个时钟上升沿采样一位。检测序列 **`10110`**（按时间顺序，先来的在左边），**允许重叠**：
```
din  : 1 0 1 1 0 1 1 0
                ↑     ↑      两次匹配（第二次复用了第一次末尾的 "10"）
```
- 采样到序列最后一位的那个上升沿之后，`match` 拉高一个周期（寄存器输出，Moore 型时序）
- 复位后重新开始，复位前的输入不算

**要求用状态机实现**（tb 只检查功能；移位寄存器写法见追问）。

## 接口
```systemverilog
module seq_detect (
  input  logic clk,
  input  logic rst_n,   // 异步复位，低有效
  input  logic din,
  output logic match
);
```

## 时序示例
```
clk    _|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_
din      1   0   1   1   0   1   1   0
match  _____________________|‾‾‾|_______|‾‾‾|_
```
