# 008 四个数中第 2 大与第 3 大之和 Middle-Two Sum

**难度**：Easy ｜ **类型**：组合逻辑 ｜ **来源**：全志科技一面

## 题目
输入四个 W bit 无符号数 `a, b, c, d`，输出其中**第 2 大和第 3 大**的两个数之和 `sum`。
有相等的数时按排序后的位置算（例如 5,5,3,1 → 第 2 大是 5，第 3 大是 3，和为 8）。

## 接口
```systemverilog
module mid2_sum #(parameter int W = 8) (
  input  logic [W-1:0] a, b, c, d,
  output logic [W:0]   sum
);
```

## 示例
| a b c d | sum |
|---|---|
| 1 2 3 4 | 5 |
| 9 9 9 9 | 18 |
| 7 0 7 0 | 7 |

## 测试
W=4 穷举（65536 组），W=8 随机。
