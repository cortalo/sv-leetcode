# 029 无毛刺时钟切换 Glitch-Free Clock Switch

**难度**：Hard ｜ **类型**：时钟 / CDC ｜ **来源**：英伟达二面「无毛刺的时钟切换电路设计」；复旦微「画时钟无毛刺切换电路」；阿里云手撕系列；兆易创新

## 题目
两个**异步**时钟 `clk0`、`clk1`，选择信号 `sel`（与两个时钟都异步）：`sel=0` 输出 `clk0`，`sel=1` 输出 `clk1`。
要求切换过程中 `clk_out` **不能出现毛刺**：
- `clk_out` 的每一个高电平段，宽度必须等于 `clk0` 或 `clk1` 的一个完整高电平（不能被截短）
- `clk_out` 的每一个低电平段，宽度不能短于两个时钟里较短的那个低电平（可以更长，切换时允许输出暂停若干个周期）
- `sel` 稳定后，`clk_out` 最终要跟随被选中的时钟
- 输入保证：`sel` 每次变化后至少保持 150ns（约 6 个 `clk1` 周期），即上一次切换完成之前不会再变
- 复位期间 `clk_out` 保持低

## 接口
```systemverilog
module clk_switch (
  input  logic clk0,
  input  logic clk1,
  input  logic rst_n,   // 异步复位，低有效
  input  logic sel,
  output logic clk_out
);
```

## 测试
`clk0` 周期 10ns、`clk1` 周期 26ns，相位无关；`sel` 在随机时刻翻转约 300 次。tb 测量 `clk_out` 每个高/低电平的宽度，并在 `sel` 稳定 150ns 之后检查输出周期是否等于被选时钟。
