# 016 串行输入被 3 整除检测 Mod-3 Detector

**难度**：Medium ｜ **类型**：状态机 ｜ **来源**：平头哥技术终面手撕真题（模三检测器）；阿里云手撕系列

## 题目
一个二进制数从 `din` **高位在前**逐位串行输入，`din_valid=1` 的拍有效。
每收到一位，这个数变为 `value = value * 2 + din`。
输出 `div3` 表示**到目前为止收到的数**能否被 3 整除：
- 复位后 `value = 0`，`div3 = 1`
- 每个有效位在时钟上升沿被接收，`div3` 在该上升沿之后更新（寄存器/状态输出）
- `din_valid=0` 的拍状态不变

## 接口
```systemverilog
module mod3_detect (
  input  logic clk,
  input  logic rst_n,     // 异步复位，低有效
  input  logic din,
  input  logic din_valid,
  output logic div3
);
```

## 示例
输入 `1, 1, 0, 0, 1`：
| 收到 | value | div3 |
|---|---|---|
| 1 | 1 | 0 |
| 11 | 3 | 1 |
| 110 | 6 | 1 |
| 1100 | 12 | 1 |
| 11001 | 25 | 0 |

## 测试
随机比特流（带随机 valid 间隔）10000 拍，并多次中途复位，逐拍比对。
