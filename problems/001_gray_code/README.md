# 001 格雷码转换 Gray Code

**难度**：Easy ｜ **类型**：组合逻辑 ｜ **来源**：阿里云「手撕代码」系列；异步 FIFO 指针同步的基础

## 题目
实现一个参数化模块，同时完成两件事：
1. 二进制 → 格雷码：`bin_i` 转换为 `gray_o`
2. 格雷码 → 二进制：`gray_i` 转换为 `bin_o`

两条通路互相独立，纯组合逻辑。

## 接口
```systemverilog
module gray_code #(parameter int W = 8) (
  input  logic [W-1:0] bin_i,
  output logic [W-1:0] gray_o,
  input  logic [W-1:0] gray_i,
  output logic [W-1:0] bin_o
);
```

## 示例（W=4）
| 二进制 | 格雷码 |
|---|---|
| 0000 | 0000 |
| 0001 | 0001 |
| 0010 | 0011 |
| 0011 | 0010 |
| 0111 | 0100 |
| 1000 | 1100 |

## 测试
- W=8：穷举 256 个值
- W=13：随机 5000 个值

## 追问

3. 深度不是 2 的幂的 FIFO 还能直接用格雷码吗？
