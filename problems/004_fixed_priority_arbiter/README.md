# 004 固定优先级仲裁器 Fixed Priority Arbiter

**难度**：Easy ｜ **类型**：组合逻辑 ｜ **来源**：华为海思二面、平头哥、芯动、复旦微；阿里云手撕系列

## 题目
N 个请求者共享一个资源，`req[i]=1` 表示第 i 个请求者申请。
仲裁器输出独热码 `gnt`，只授权给**编号最小**的那个请求者（`req[0]` 优先级最高，`req[N-1]` 最低）。
没有请求时 `gnt = 0`。纯组合逻辑。

## 接口
```systemverilog
module fixed_arb #(parameter int N = 8) (
  input  logic [N-1:0] req,
  output logic [N-1:0] gnt
);
```

## 示例（N=4）
| req | gnt |
|---|---|
| 0000 | 0000 |
| 1010 | 0010 |
| 1100 | 0100 |
| 1111 | 0001 |

## 测试
N=1、N=3、N=8 穷举，N=32 随机。
