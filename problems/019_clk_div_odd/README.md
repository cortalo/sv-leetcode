# 019 奇数分频（50% 占空比）Odd Clock Divider

**难度**：Medium ｜ **类型**：时序逻辑 / 时钟 ｜ **来源**：字节 AI Lab「三分频、占空比 50%」；OPPO「手撕三分频，追问可改进的地方」；芯源三分频；CSDN 百题斩 #2、#30

## 题目
把 `clk` 做 N 分频（N 为奇数，N ≥ 3），输出 `clk_out`：
- 周期 = N 个 `clk` 周期
- **占空比严格 50%**：高电平 N/2 个周期（例如三分频高 1.5 个周期、低 1.5 个周期）
- 复位期间 `clk_out = 0`；复位释放后几拍内开始正常翻转即可（不检查相位）

## 接口
```systemverilog
module clk_div_odd #(parameter int N = 3) (
  input  logic clk,
  input  logic rst_n,     // 异步复位，低有效
  output logic clk_out
);
```

## 测试
N = 3、5、7、9 四个实例，tb 测量每个周期的长度和高电平宽度（精确到 0.01ns）。
