# 013 异步复位同步释放 Reset Synchronizer

**难度**：Easy ｜ **类型**：时序逻辑 / 复位 ｜ **来源**：OPPO、芯动科技（二面追问第二级会不会亚稳态）、汇顶；CSDN 百题斩 #4

## 题目
外部来的复位 `arst_n` 与 `clk` 异步。设计一个复位同步器，输出给内部逻辑使用的 `rst_n_sync`：
- **异步复位**：`arst_n` 拉低时，`rst_n_sync` **立即**变 0，不需要等时钟沿
- **同步释放**：`arst_n` 拉高后，`rst_n_sync` 在**第 2 个**时钟上升沿之后才变 1（两级同步）

## 接口
```systemverilog
module reset_sync (
  input  logic clk,
  input  logic arst_n,
  output logic rst_n_sync
);
```

## 时序示例
```
clk         _|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_
arst_n      ‾‾‾‾|_______|‾‾‾‾‾‾‾‾‾‾‾‾‾
rst_n_sync  ‾‾‾‾|_____________|‾‾‾‾‾‾‾
                         ↑1  ↑2
```

## 测试
在时钟周期内随机时刻拉低/拉高 `arst_n` 200 次，检查：拉低后立即为 0；释放后第 1 个上升沿之后仍为 0；第 2 个上升沿之后为 1。

## 追问
1. 为什么不直接用异步复位？直接释放会有什么问题？（recovery / removal）
2. 第二级触发器会不会进入亚稳态？为什么这个电路可以接受？
3. 为什么不全部用同步复位？
4. 多个时钟域时复位怎么处理？复位释放的顺序有要求吗？
