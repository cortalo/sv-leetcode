# 002 判断温度计码 Thermometer Code Check

**难度**：Easy ｜ **类型**：组合逻辑 ｜ **来源**：字节跳动面试真题

## 题目
温度计码（thermometer code）是从最低位开始连续若干个 1、其余全为 0 的编码，例如（W=8）：

```
00000000  00000001  00000011  00000111 ... 01111111  11111111
```

给定一个 W bit 的输入 `in`，判断它是不是合法的温度计码：是则 `is_thermo = 1`，否则为 0。
全 0 和全 1 都算合法。

## 接口
```systemverilog
module thermo_check #(parameter int W = 8) (
  input  logic [W-1:0] in,
  output logic         is_thermo
);
```

## 示例（W=8）
| in | is_thermo |
|---|---|
| 0000_0000 | 1 |
| 0000_0111 | 1 |
| 1111_1111 | 1 |
| 0000_0101 | 0（中间有 0 断开）|
| 1110_0000 | 0（1 没有从最低位开始）|

## 测试
W=1、W=8、W=16 全部穷举。
