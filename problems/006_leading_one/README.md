# 006 最高位 1 的位置 Leading One Detector / 优先编码器

**难度**：Easy ｜ **类型**：组合逻辑 ｜ **来源**：rsxk 真题「找到序列最高位的 1」；浮点规格化、LZC 的基础

## 题目
输入 W bit 的 `in`，输出其中**最高位的 1** 所在的位置 `idx`（从 0 开始数）。
- `in` 不为 0 时 `valid = 1`
- `in == 0` 时 `valid = 0`，`idx` 不做要求

## 接口
```systemverilog
module lead_one #(parameter int W = 16) (
  input  logic [W-1:0]         in,
  output logic [$clog2(W)-1:0] idx,
  output logic                 valid
);
```
（W ≥ 2）

## 示例（W=8）
| in | idx | valid |
|---|---|---|
| 0000_0001 | 0 | 1 |
| 0010_1100 | 5 | 1 |
| 1000_0000 | 7 | 1 |
| 0000_0000 | - | 0 |

## 测试
W=5、W=16 穷举；W=32 随机（偏向稀疏输入）。
