# 003 统计 1 的个数 Popcount

**难度**：Easy ｜ **类型**：组合逻辑 ｜ **来源**：常见基础题；温度计码转二进制、汉明距离的基础

## 题目
输入 W bit 的 `in`，输出其中 1 的个数 `cnt`。

## 接口
```systemverilog
module popcount #(parameter int W = 16) (
  input  logic [W-1:0]         in,
  output logic [$clog2(W+1)-1:0] cnt
);
```
注意输出位宽是 `$clog2(W+1)`：W=16 时最多 16 个 1，需要 5 bit。

## 示例
| in (W=8) | cnt |
|---|---|
| 0000_0000 | 0 |
| 1011_0001 | 4 |
| 1111_1111 | 8 |

## 测试
W=1、W=7、W=16 穷举；W=32 随机。
