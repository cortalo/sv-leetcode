# 015 毛刺滤波 Glitch Filter

**难度**：Medium ｜ **类型**：时序逻辑 ｜ **来源**：兆易创新「输入的信号有噪声，噪声不超过两个周期，怎么滤掉噪声」

## 题目
`din` 与 `clk` 同步，但上面可能有宽度为 1~2 个周期的噪声脉冲。设计滤波器输出 `dout`：
- 每个时钟上升沿采样 `din`
- 当**连续 3 次**采样到的值相同（本次 + 前两次），并且与当前 `dout` 不同时，`dout` 在这个上升沿更新为该值
- 因此宽度 ≤ 2 个周期的脉冲会被滤掉，宽度 ≥ 3 个周期的电平变化会在第 3 次采样时传到输出
- 复位时 `dout = 0`，并且认为之前的采样值都是 0

## 接口
```systemverilog
module glitch_filter (
  input  logic clk,
  input  logic rst_n,   // 异步复位，低有效
  input  logic din,
  output logic dout
);
```

## 时序示例
```

           (2拍噪声)      ↑1  ↑2  ↑3

```

## 测试
随机生成长电平段 + 1~2 拍的毛刺，逐拍比对。
