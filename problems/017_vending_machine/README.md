# 017 自动售货机 Vending Machine

**难度**：Medium ｜ **类型**：状态机 ｜ **来源**：经典手撕题；CSDN 百题斩 #11；阿里云手撕系列「饮料机」

## 题目
饮料单价 **1.5 元**。机器接受 0.5 元和 1 元硬币，每个时钟周期最多投一枚：

| coin | 含义 |
|---|---|
| 2'b00 | 没有投币 |
| 2'b01 | 投入 0.5 元 |
| 2'b10 | 投入 1 元 |
| 2'b11 | 无效，当作没有投币 |

- 累计金额 **≥ 1.5 元**时出一瓶饮料：投入最后一枚硬币的那个上升沿之后，`drink` 拉高一个周期
- 如果累计是 2 元，同时 `change` 拉高一个周期（找零 0.5 元）
- 出货后累计金额清零，开始下一轮
- 其他时候 `drink = 0, change = 0`

## 接口
```systemverilog
module vending (
  input  logic       clk,
  input  logic       rst_n,   // 异步复位，低有效
  input  logic [1:0] coin,
  output logic       drink,
  output logic       change
);
```

## 测试
随机投币序列 8000 拍，逐拍比对。
