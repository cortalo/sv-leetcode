# 009 边沿检测 Edge Detector

**难度**：Easy ｜ **类型**：时序逻辑 ｜ **来源**：兆易创新「同一个时钟沿，根据电平变化产生一个脉冲」；AMD「双沿检测」；兆芯二面画边沿检测电路

## 题目
`din` 是与 `clk` 同步的单 bit 信号（在时钟上升沿之后变化）。检测它的边沿：
- `rise`：`din` 由 0 变 1 的那一个周期为 1
- `fall`：`din` 由 1 变 0 的那一个周期为 1
- `both`：任意边沿的那一个周期为 1

"那一个周期" 指 `din` 刚变成新值、到下一个时钟上升沿之前的这一拍（即用上一拍寄存的 `din` 与当前 `din` 比较，输出是组合逻辑）。

## 接口
```systemverilog
module edge_detect (
  input  logic clk,
  input  logic rst_n,   // 异步复位，低有效；复位时认为上一拍的 din = 0
  input  logic din,
  output logic rise,
  output logic fall,
  output logic both
);
```
