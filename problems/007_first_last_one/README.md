# 007 第一个 1 和最后一个 1 First & Last One

**难度**：Easy ｜ **类型**：组合逻辑 / 位运算 ｜ **来源**：平头哥一面「寻找序列第一个 1」；字节二面「找最先/最后出现的 1」；CSDN 百题斩 #34

## 题目
输入 W bit 的 `in`，输出两个**独热码**：
- `first_oh`：只保留 `in` 中**最低位**的 1（第一个 1）
- `last_oh` ：只保留 `in` 中**最高位**的 1（最后一个 1）

`in == 0` 时两者都为 0。

**要求**：尽量只用按位运算（与、或、非、加减），不用 for 循环逐位扫描。（tb 不检查写法，自觉😄）

## 接口
```systemverilog
module first_last_one #(parameter int W = 16) (
  input  logic [W-1:0] in,
  output logic [W-1:0] first_oh,
  output logic [W-1:0] last_oh
);
```

## 示例（W=8）
| in | first_oh | last_oh |
|---|---|---|
| 0010_1100 | 0000_0100 | 0010_0000 |
| 1000_0000 | 1000_0000 | 1000_0000 |
| 0000_0000 | 0000_0000 | 0000_0000 |

## 测试
W=16 穷举；W=33 随机。
